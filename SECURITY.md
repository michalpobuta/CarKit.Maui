# Security policy

## Supported versions

Security fixes go to the latest released version of the CarKit.Maui packages.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's private reporting instead: open the
**Security** tab of this repository and choose **Report a vulnerability**.

Include the affected package and version, the platform (CarPlay, Android Auto or both), the steps to reproduce the
problem and its impact. You can expect a first response within 7 days. Once a fix is available, the advisory is
published together with the release that contains it.
